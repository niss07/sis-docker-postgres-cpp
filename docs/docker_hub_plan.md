# Docker Hub Publishing Plan

This document describes the plan for publishing Docker images to Docker Hub.

## Accounts
Each student will create a Docker Hub account using their official school email.

## Images
The following images will be published:
- PostgreSQL database image
- C++ application image

## Naming Convention
Images will follow this format:
[schoolemail-username]/sis-project-[component]:[tag]

Example:
itu20240001/sis-project-postgres:v1.0

## Requirements
- Images must be publicly accessible.
- Docker Hub links will be included in the main README.md file.

## Responsibility
Student 2 is responsible for building and pushing the images and coordinating with Student 3 for testing.
